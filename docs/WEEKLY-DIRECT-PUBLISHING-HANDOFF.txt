READY LOCALLY
Import → Edit → Preview publication → Publish. No per-article developer, GitHub,
build, deployment or registry sync. Private drafts stay in the existing private EU D1.
Approved content, rendered HTML, covers, published revisions and frozen ranking
baselines live in the existing Weekly EU D1. Every mutation uses one D1 batch
transaction for article/revision/URL history/engagement registration/version/outcome.
Repeated operations return their committed result. Global and per-edition checks
reject races; an older saved draft also cannot silently overwrite a newer publication.
Unknown fields, source/timestamp/ranking errors remain server-validated.

Article list: Edit, Unpublish, Delete → Trash; Trash offers Restore and explicitly
confirmed Permanently delete. Editing automatically saves a separate private working
copy. Public content stays unchanged until the owner confirms Update published article.
Restoration leaves content unpublished. Published history recovery creates a new
revision. Unpublish/Trash retains comments and reactions but denies public access.
Permanent article deletion removes article content and published history, retaining
ID/number/URL tombstones and PRIVATE engagement. Engagement has a separate explicit
moderation deletion. Separate drafts/exports and provider backups are not erased.
See WEEKLY-DIRECT-PUBLISHING-GUIDE.txt for exact owner buttons and recovery commands.

Dynamic output: complete HTML (including tables), newest-first paginated archive,
direct refresh, canonical/BlogPosting metadata, branded PNG/SVG, RSS, sitemap shards,
HTML site-map link and Home latest teaser. Publication updates appear on the next
request. Dynamic responses use browser/CDN no-store; proposed cache bypass backs this
up. Existing downloaded pages, screenshots and search/social caches cannot be recalled.
Public reads only accept status=published. Withdrawn/historical URLs return 410;
renamed published URLs redirect to the current slug. JS is unnecessary for reading.
No unverified rehearsal facts are being promoted or newly verified by this work.
