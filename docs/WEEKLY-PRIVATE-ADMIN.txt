WHAT IS IMPLEMENTED
The existing authoring page, full article JSON, validator, renderer, manual ranking
import and export remain the same. The private Worker serves only an explicit
static asset allowlist, after authenticating every request. D1 stores private
working copies and complete revision snapshots, separate from public articles.
Save accepts incomplete values in the contract's required shape. Export requires
the existing full validator. Neither operation publishes or verifies the facts.
500 KB maximum article; paged draft/revision lists (20 at a time).
Expected revision + SHA-256 source hash prevent stale tabs overwriting newer work.
History recovery loads an old copy; saving appends a new revision. Stable edition
IDs cannot change after assignment. Original published metadata is preserved.
No automatic expiration of articles, private drafts or their revisions.
Explicit draft deletion currently requires an authorized maintenance operation;
there is no new deletion button, and no scheduled job touches private drafts.

Google's enabled MFA is not by itself evidence that native Google Access login
enforces MFA. Require independent Access MFA (TOTP/authenticator) for this app,
no email-code fallback, no bypass/service-token policy, exact owner inclusion.

independent Access TOTP does not populate the IdP AMR claim. The deployed repair
retains RS256/issuer/audience/expiry/owner verification and pins independent MFA
to the live Access application and its exact owner policy. Every request reads

and exactly the pinned owner Allow policy. Disabled MFA, widened policy, wrong
domain/audience, API failure, missing credential or old pre-policy token denies
access. Tokens must be application tokens, not launcher/organization tokens.
