Space for every possible set

A pre-match sheet keeps all possible sets: one for the social one-set format, three for best of three, or two normal sets plus a clearly labelled deciding match-tiebreak column. Each normal set cell has a games area and a smaller optional TB-points area. Names are optional in blank mode.

Example

For a named doubles match with a deciding 10-point match tiebreak, enter two players per team. Print two set-game columns, a match-tiebreak-points column, integrated optional set-tiebreak details and game-by-game writing space.
