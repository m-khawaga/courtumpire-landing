Standard six-game scoring & tiebreak reference

A concise reference for the supported standard singles rules. This reference is for six-game sets; it is not appended to other documents.

Standard advantage games

Points progress through love, 15, 30 and 40. At deuce, two consecutive points are needed: advantage, then game. The server changes after each game.

Tie-break sets

A set normally needs six games with a two-game lead. At 6–6, play a tiebreak to at least seven points with a two-point lead; record the set as 7–6.

Tiebreak service

The first server serves one point. The other serves two, then turns of two alternate. Serves alternate deuce/right and ad/left halves. Change ends after every six points under the standard rule.

Next set and court ends

The first tiebreak server receives in the next set’s first game. Change ends after odd games; serving half and physical court end are different. A 10-point match tiebreak may replace a deciding set when agreed, still won by two.

Reference: ITF 2026 Rules 5–7, 10, 14, 17 and Appendix VI. Other formats and alternative end-change rules are outside this sheet.
