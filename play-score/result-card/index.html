Supported completed results

Singles advantage games, one tie-break set, best of three tie-break sets, or a deciding 10-point match tiebreak. With six-game sets, completed results are 6–0 through 6–4, 7–5 or 7–6. With four-game sets, use 4–0, 4–1, 4–2, 5–3 or 5–4. Four-game sets use a standard seven-point tiebreak at 4–4; advantage games remain unchanged. A deciding match tiebreak replaces Set 3 and uses points, not games.

Example

Alex wins 6–3, 6–4: no third set is needed. If Set 3 was entered earlier, clear it explicitly or correct the earlier scores. At 7–6, optional tiebreak points such as 12–10 appear as each player’s own parenthesized superscript. Missing detail is never invented.

Only completed results can be exported. The editor checks the format; it does not independently verify manually entered match results. Instructions and validation messages stay out of the exported image.
