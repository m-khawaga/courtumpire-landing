Play & Score

Tennis scoreboard
and guided demo

Keep a singles match here, or try a separate demonstration. No watch connection, account or Android synchronization is involved. Names update immediately; format and first-server changes apply when starting a new match.

Start a match to see the live score. The serving player is identified beside the score.

Supported formats

Singles only, using advantage games. Choose first to six games with a tiebreak at 6–6, or first to four games with a tiebreak at 4–4. Sets need a two-game margin before the tiebreak; both use a standard seven-point, win-by-two tiebreak. Four-game completed scores include 4–0, 4–1, 4–2, 5–3 and 5–4. Choose a social one-set match, best of three regular sets, or best of three with a 10-point match tiebreak instead of the third set. All tiebreaks require a two-point lead. Standard six-point tiebreak end changes apply.

Example

At 40–40, A wins a point: advantage A. If B wins the next, it returns to deuce. Undo restores the entire previous score, including the server. The demo walks through this using its own point history.

Save data stays in this browser. Storage failures leave the current match usable. Point entry stops at match completion. Export score produces a branded image of completed or in-progress state. Reset score clears scores and undo history after confirmation while keeping player names, the match format and configured starting server.

Rules checked against ITF Rules of Tennis (2026), Rules 5–7, 10, 14, 17 and Appendix VI. This website supports the formats described here; event-specific variations may differ.
