    Clear, remove or unpublish an edition
    Clear editor removes only this browser’s working copy. It does not delete a saved file or change the website.
    Delete saved draft removes the selected private saved source through the local command below, with a source-hash check and explicit confirmation. Your original input, exports and private backups are separate files.
    Import the saved draft to identify it; run the command from the website worktree.
    Unpublish: use npm run weekly:import -- unpublish FILE --expected HASH, review the rebuilt website, then separately approve website deployment and registry synchronization. Exporting here never unpublishes a live page.
    Permanent delete: first unpublish, then use node scripts/weekly-remove.mjs permanent ID --expected HASH --confirm "DELETE ID". This removes the withdrawn local source and redirects, retaining publication tombstones and historical comparison snapshots. After the approved registry marks the edition inactive, its engagement can be deleted with explicit confirmation in moderation’s Advanced settings. Git history, original downloads and provider backups are outside this deletion.
