4. Publish

Import → Edit → Preview → Publish. Publication makes the reviewed edition public immediately. Saving a private draft and exporting do not publish.

Publication outcome and recovery

If a request times out, check its outcome before trying again. Retrying uses the same operation key and cannot create a second edition.

Articles and private Trash

Published revision recovery

Recover loads an old copy privately. Preview and update create a new revision; no historical revision is overwritten.
